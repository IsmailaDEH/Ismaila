# LinkedIn — Guide de mise à jour

## 1. Ajouter le portfolio à ton profil

### Site web dans les coordonnées
1. Va sur ton profil LinkedIn
2. Clique sur **« Modifier le profil »** (crayon en haut à droite)
3. Dans la section **« Coordonnées »**, clique sur **« Modifier »**
4. Dans **« Site web »**, ajoute :
   - URL : `https://ismailadeh.github.io`
   - Type : *Portfolio* (ou *Autre*)
5. Sauvegarde

### Section « Sélection » (Featured)
1. Sur ton profil, fais défiler jusqu'à **« Sélection »**
2. Clique sur **«+ »** → **« Lien »**
3. Colle `https://ismailadeh.github.io`
4. Titre : *Portfolio — Physique Théorique & Quantique*
5. Description : *Simulations quantiques, modèle d'Ising, pendule double chaotique et plus.*
6. Sauvegarde

### Section « Projets »
1. Dans **« Ajouter une section » → « Projets »**
